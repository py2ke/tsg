# Surfing Goat Beach Menu

Quero que monte um cardápio de quiosque de praia, com itens separados por tipos, conforme a lista que vou enviar
O cardápio deve ter cara de praia, surf e diversão, o nome do quiosque é The Surfing Goat e o cardápio deve ter dois formatos, um impresso, A4, e o outro deve ser uma tira, para ser usado na web, visto no celular
Use imagens de drinks e pratos, de acordo com o que tiver em cada sessão, não precisa ser para cada prato ou drink, apenas uma imagem inicial, ilustrando a sessão
O logo deve ter um destaque e tenho uma imagem ambientada, com pessoas sentadas às mesas que pode ser usada
Use tema de areia, azul, céu e mar, remeter ao surf sutilmente, nada muito forçado
